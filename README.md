# Sistema de Classificação de Notícias
Aplicação de terminal para cadastro e classificação de notícias.

---
## Requisitos

Antes de executar o projeto, é necessário ter instalado:

- Java 17 ou superior

Para verificar se o Java está instalado:
```bash
java -version
```
---
## Compilação

No terminal, acesse a pasta do projeto e execute:
```bash
javac -d out src/**/*.java
```
---
# Execução

Após compilar o projeto, execute:
```bash
java -cp out Main
```
---
# Funcionalidades

O sistema permite:

- cadastrar notícias manualmente;
- classificar notícias automaticamente;
- listar notícias cadastradas.
---
# Encerramento

Para sair do programa, utilize a opção ``4 - sair`` no menu principal.
